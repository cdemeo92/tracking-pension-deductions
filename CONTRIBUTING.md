# Contributing

Thanks for helping improve Tracking pension deductions. Bug reports, documentation updates, and focused code changes are welcome.

## Report an issue

Include what you expected, what happened, and the steps needed to reproduce it. For incorrect calculations or payslip extraction, provide a minimal example with synthetic or fully redacted figures. Do not share real payslips, tracker pages, or personal identifiers.

## Set up the project

Install the prerequisites listed in the [README](README.md), then install the dependencies:

```sh
npm ci
uv sync --extra pdf
```

The PDF extra is only needed for the optional `pdfplumber` extraction fallback. Run the local preview with `npm run dev`.

## Make and verify changes

- Edit tracker source in `assets/`; `dist/template.html` is generated by `npm run build` and should not be edited directly.
- Keep tracker state changes in `scripts/state.py`, which validates updates to the HTML page.
- Add or update tests when changing calculations, extraction, validation, or user-facing behavior. Use synthetic data in tests and examples.
- Run the project checks before submitting:

  ```sh
  npm run lint
  npm test
  ```

## Submit a change

Keep changes focused and describe the problem they solve. In your pull request, summarize the behavior changed and the checks you ran. Call out any known limitations, especially when a change affects tax rules or payslip interpretation.
